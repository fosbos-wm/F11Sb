# Das Experiment – interaktive Lerneinheit (P/P)

- `das-experiment.html` – die Lerneinheit. Läuft in der F11Sb-App als Vollbild-Overlay
  (Button „Stunde starten“ im Lernpfad Pädagogik/Psychologie, LB 1).
- In der App: anonymer Klassenvergleich (nur Gruppe + Wörterzahl, Collection `experimentErgebnisse`)
  und Häkchen „Stunde gemacht“ nach dem Abschlussquiz. Quizergebnisse bleiben lokal im Browser.
- Als eigenständige Datei geöffnet funktioniert sie weiterhin ohne Firebase (Werte von Hand eintragen).
